# Data Analysis & Visualization Portfolio

A five-project data analysis and visualization portfolio demonstrating practical skills in Python, pandas, NumPy, Matplotlib, Seaborn, SciPy, Jupyter, statistical analysis, data cleaning, visualization, and business communication.

## Projects

### 1. Retail Sales Analysis
Analyzes sales, profit, categories, regions, discounts, and customer/order patterns using a Superstore-style retail dataset.

### 2. Student Performance Analysis
Analyzes student scores, attendance, study hours, correlations, and performance differences using simulated data.

### 3. Weather Analysis
Analyzes temperature trends, rainfall, seasonality, distributions, and weather relationships using simulated data.

### 4. Healthcare Patient Analysis
Analyzes patient conditions, risk factors, healthcare utilization, missing values, duplicates, and correlations using simulated data.

### 5. Finance Market Analysis
Analyzes returns, sector performance, volatility, sentiment, and market relationships using simulated data.

## Important Data Note

Project 1 uses the supplied Superstore-style retail dataset.

The finance project is an educational analytics exercise and is not investment advice.
