# Business / Analytical Recommendations
These recommendations are for portfolio demonstration, not investment advice.
1. Use sector-level return and volatility tables for dashboard segmentation.
2. Track monthly return distributions rather than relying on single-period observations.
3. Treat sentiment as an additional descriptive variable and test it with appropriate statistical methods before drawing conclusions.
4. Pair return measures with volatility to communicate risk and dispersion.
5. For real financial applications, use verified market data, transaction-cost assumptions, regulatory controls and out-of-sample validation.
