# Project 4 — Healthcare Patient Analysis

**Important:** This is a simulated healthcare dataset created for learning and portfolio practice. It contains no real patient records and has no clinical validity.

## Results
- Raw rows: 1,002
- Clean rows: 1,000
- Duplicate rows removed: 2
- Average age: 51.7
- Average BMI: 26.7
- Average annual visits: 4.35
- Synthetic high-risk rate: 30.2%
